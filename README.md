## Project Contents

This repository is a Next.js workshop app with multiple interactive sections:

- `src/app/dashboard` — a dashboard area with tools and creative widgets.
- `src/app/games` — a library of browser games built with React.
- `src/app/graphs` — a gallery of chart and graph visualizations.
- `src/app/api` — backend routes for image generation and search features.
- `src/app/i18n` — internationalization support and language provider.
- `src/app/_componets` — shared UI components, layout, sidebar, cards, and widgets.
